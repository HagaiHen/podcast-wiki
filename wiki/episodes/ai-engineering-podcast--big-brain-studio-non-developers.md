# How Do You Turn the Whole Company Into a Development Team?

[[people/doron]] and [[people/oded]] of Big Brain, monday.com's data group, describe Big Brain Studio, which lets non-developers build apps on company data.
Layer one was Kramer, an agent that answers data questions in plain language and applies each user's permissions; shared static HTML artifacts then leaked data, which pushed the team toward live, permission-aware apps.
Giving non-developers the developer stack (PRs, CI, deploys) through skills failed. A broker that deploys straight from the user's Claude or Cursor in about 20 seconds, with scoped temporary credentials, worked.
About 2,900 apps in three months raise the next problems: one source of truth, verification, duplicates, and docs written for the user's LLM.
Next: making the platform a sub-agent for autonomous agents. The lesson: enable domain experts to build their own tools instead of building for them.
