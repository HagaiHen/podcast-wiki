# WebMCP Clearly Explained (and How to Make $$)

[[people/greg-isenberg]] and guest Vinny explain WebMCP, an experimental Chrome feature from Google and Microsoft (launched in February). Websites expose a concise list of agent tools (search, compare, add to cart, apply coupon) that the user's own agent calls inside the browser session.
Demo: an espresso-gear shop with 16 tools, where the agent compares machines against counter width and needs, highlights matching specs on the page, and adds accessories to the cart.
Versus alternatives: no DOM scraping or screenshots (computer use, browser MCP); no API keys or OAuth, since tools inherit the logged-in session and can be conditional on login state; and no in-app agent whose tokens the vendor pays for.
Framing: SEO (can Google understand the page?) → AEO (can AI cite it?) → WebMCP (can the agent finish the job?). Best fits: compatibility-driven commerce, SaaS admin consoles, read-only self-service in regulated industries, and internal tools.
Two startup ideas: an agent-conversion agency for boring local businesses ($2–10k setup plus a monthly retainer), and an "agent mystery shopper" that tests whether agents can complete key journeys and reports where they get stuck.
