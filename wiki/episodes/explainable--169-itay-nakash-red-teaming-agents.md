# #169 Breaking Agents From the Inside: Prompt Injection, Red Teaming and Models That Lie, With Itay Nakash

[[people/mike-erlihson]] asks IBM Research's [[people/itay-nakash]] why multi-agent systems rarely reach production; his answer is that they aren't trustworthy enough yet.
He separates "cyber with AI" from "cyber for AI" and explains indirect prompt injection, the "foot in the door" attack that broke ReAct agents 80–90% of the time, and shallow safety alignment.
Defenses run from prompt warnings to reflection models, removing permissions, and deterministic tool guards (ToolGuard). CRAFT shows τ-bench's polite simulated users overstate how robust agents are.
On LLM safety: models that invent explanations for a leaked answer, and models with unstable opinions.
Tips for agent evals, advice against running OpenClaw-style agents on personal accounts, and a research path into the field.
