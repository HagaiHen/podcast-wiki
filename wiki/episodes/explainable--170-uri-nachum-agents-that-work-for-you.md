# #170 Uri Nachum on AI Agents That Work for You

[[people/uri-nachum]], an AI expert at fintech Tipalti with 18 years in development, defines an agent as code that calls an LLM with a feedback loop and tools. By that definition a Claude or ChatGPT chat is already an agent.
He runs agents at home: an AC wired in through Sensibo, a smart-electricity setup for Yom Kippur, and weather alerts on WhatsApp. He keeps about 1.5–3 Claude Code agents running nonstop.
Fearing an "AI winter" when subsidized frontier models get scarce, he builds open-source, agent-tailored CLIs, tools for passing a smart model's process to weaker ones, and local hardware (Jetson, DGX Spark) for open models.
On robotics: local compute is essential, and a small robot like Reachy Mini teaches real-time agent work. He also runs the Jetson AI Lab community.
Model personalities persist whatever the prompt; he expects personalization to come through fine-tuning. Career advice: think agent-first, and care about the people (and agents) around you.
