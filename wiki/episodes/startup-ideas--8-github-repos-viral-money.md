# 8 GitHub Repos To Go Viral and Make Money

[[people/greg-isenberg]] tours five repos and three skills, each paired with a way to make money: Brag (launch videos), Agent Reach (social-web customer research), Voice Studio (local open-source voice cloning and dubbing), PPT Master (notes → editable deck in your template), and OpenRig (builder + checker agent teams for Claude Code and Codex).
Skills: Free Tools (Corey Haynes; lead-magnet calculators), Grill Me (Matt Pocock; interviews you and logs assumptions), and Impeccable (Paul Bakaus; design critique and polish for coding agents).
Recurring theme: permissionless outreach. Do the work (a launch video, design fixes) and send it instead of a cold email, then grow services on retainer into technology.
"SaaS is evolving": boring businesses still do manual work around software they already pay for.
His pick to try first is Brag, then Agent Reach.
