# AI Engineering

Building reliable, useful systems with LLMs and agents: what goes into context, how knowledge is retrieved, and how to make agent behavior trustworthy.

## Concepts
- [[concepts/harness-engineering]]: environment that lets agents run long and correctly
- [[concepts/agent-ready-codebase]]: make the repo operable by agents
- [[concepts/test-driven-development]]: frozen failing tests keep agents honest
- [[concepts/context-engineering]]: context makes the difference; keep it lean and current
- [[concepts/wiki-retrieval]]: finding the right page; multiple guesses, ranking, RAG/hybrid
- [[concepts/ai-guardrails]]: enforce rules technically, not by instruction
- [[concepts/ai-verification]]: read outputs, demand proof, check sources
- [[concepts/llm-wiki]]: Karpathy's raw/wiki/schema pattern
- [[concepts/open-knowledge-format]]: Google's universal knowledge-file format
